## Automated smoke script

Run `node scripts/production-readiness-smoke.mjs` against localhost or a Vercel branch Preview after setting `APP_BASE_URL`, `NEXT_PUBLIC_SUPABASE_URL`, and the publishable key. It checks the health route, public pages, and basic accessibility markup. With two test accounts and a disposable estimate, it verifies owner/other-account reads through Supabase REST and the app API. Attach a test photo to that estimate to also check signed-URL isolation in private Storage.

For authenticated checks, provide dedicated Free and Pro test-account credentials through `WORKCRAFT_E2E_FREE_EMAIL`, `WORKCRAFT_E2E_FREE_PASSWORD`, `WORKCRAFT_E2E_PRO_EMAIL`, and `WORKCRAFT_E2E_PRO_PASSWORD`. Set `WORKCRAFT_E2E_CROSS_ACCOUNT_ESTIMATE_ID` to a disposable test estimate and `WORKCRAFT_E2E_ESTIMATE_OWNER` to `free` or `pro` to verify the owner can read it and the other account cannot.

Stripe webhook checks mutate a payment fixture and are disabled by default. Run them only against localhost or a `-git-` Vercel branch Preview with Stripe **test-mode** credentials, `WORKCRAFT_E2E_ALLOW_FIXTURE_MUTATIONS=1`, and a dedicated pending test payment identified by `WORKCRAFT_E2E_PAYMENT_ID` and `WORKCRAFT_E2E_CONNECT_ACCOUNT_ID`. The script also submits concurrent copies of a no-op event to verify one durable claim. Never point it at Production or a real payment. These direct signed requests test the handler; separately confirm that Stripe's Preview destination shows successful provider delivery attempts.

## Rollback

The prepared webhook claim migration is additive and leaves the existing boolean claim RPC available for old deployments. Apply it before deploying the route that uses the state-aware RPC. If deployment rollback is needed, the prior route continues to use the existing RPC; leave the additive database function in place. Do not delete webhook idempotency records or user data as an ad hoc rollback. Restore a backup only for a verified data-integrity incident, after the restore process itself has been tested.
